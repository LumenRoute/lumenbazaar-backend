# Support

Use GitHub issues for reproducible API, SDK, worker, and MCP defects or scoped feature requests.
Include the affected endpoint or package, sanitized request shape, expected behavior, actual behavior,
and the smallest safe reproduction.

Do not post database credentials, Redis URLs, secret keys, signed authorizations, or private payment
records. Report vulnerabilities through the private process in `SECURITY.md`.

Maintainers provide best-effort community support. Public testnet services have no availability or
settlement guarantee.
